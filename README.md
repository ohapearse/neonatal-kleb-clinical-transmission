# Klebsiella transmission on the Chatinkha nursery

This github repository contains the Rmarkdown file and input data to create the figures for the analysis of Klebsiella pneumoniae transmission on the Chatinkha nursery. 

The Rmarkdown file is in the code folder. 

Data are in the data_markdown folder. To remove potentially identifiable data such as dates of birth and admissions, some data has been summarised or jittered. 

## Citation

Pearse et al. Extended-Spectrum Beta-Lactamase Klebsiella pneumoniae on a Malawian neonatal unit is amplified by neonates and transmitted by maternal hands, cots and ward surfaces, medRxiv DOI: https://doi.org/10.1101/2025.08.13.25333346
